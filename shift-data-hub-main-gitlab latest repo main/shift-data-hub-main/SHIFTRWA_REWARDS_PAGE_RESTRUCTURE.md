## DESIGN NOTES FOR TOMER

### Color Scheme
- **Airdrop Section**: Cyan/Turquoise (#00D4AA) — energetic, action-oriented
- **Loyalty Section**: Gold/Amber (#F7A23B) — premium, trusted
- **CTA Buttons**: Bright cyan (#00D4AA) with hover glow effect
- **Background**: Dark navy (#0e1117) with subtle gradient overlay

### Layout Recommendations

**Desktop View:**
- Hero: Side-by-side Airdrop (left) & Loyalty (right)
- Sections: Full-width cards with consistent padding
- CTAs: Sticky header with all three buttons

**Mobile View:**
- Hero: Stacked tabs (Airdrop / Loyalty toggle)
- Sections: Full-width, single column
- CTAs: Bottom sticky bar with vertical button stack

### Typography
- Headline: Bold, 36-44px (Airdrop & Loyalty titles)
- Subheading: 18-24px, semi-bold
- Body: 14-16px, regular weight
- CTA Text: 14px, bold, all-caps with icon

### Icons to Include
- 🚀 Rocket (Airdrop - movement, energy)
- 💎 Gem (Loyalty - premium value)
- 🏆 Trophy (Leaderboard ranking)
- 🎖️ Medal (Badges achievement)
- 📜 Scroll (Certificates)
- 📊 Chart (Performance tracking)

### Animations
- Fade-in on scroll (each major section)
- Hover effects on buttons (scale 1.05, shadow increase)
- Live leaderboard ticker (top 3-5 positions rotating)
- Pulse animation on primary CTAs
- Smooth tab transition on mobile
